# Git: рабочая папка, индекс и коммит

## Состояния Git

### Рабочая папка

Рабочая папка — это файлы проекта, которые находятся на компьютере и с которыми я сейчас работаю. Здесь появляются новые изменения после редактирования файлов.

### Индекс

Индекс — это область, куда добавляются изменения, которые я хочу включить в следующий коммит. Для добавления изменений используется команда `git add`.

### Коммит

Коммит — это сохранённая версия изменений в истории Git. Коммит создаётся командой `git commit`.

## Git и GitHub

Git — это система контроля версий, которая работает локально и позволяет отслеживать изменения в проекте.

GitHub — это онлайн-платформа для хранения Git-репозиториев, совместной работы и публикации проектов.

Git может работать без GitHub. GitHub использует Git для хранения и совместной работы с репозиториями.

## git diff и git diff --staged

`git diff` показывает различия между рабочей папкой и индексом. То есть команда показывает изменения, которые ещё не были добавлены в индекс с помощью `git add`.

`git diff --staged` показывает различия между индексом и последним коммитом. То есть команда показывает изменения, которые уже добавлены в индекс и попадут в следующий коммит.

Таким образом:

- `git diff` — рабочая папка → индекс.
- `git diff --staged` — индекс → последний коммит.
## Использованные команды

### git status

`git status` показывает текущее состояние репозитория. Он показывает изменённые, новые и подготовленные к коммиту файлы.

### git diff

`git diff` показывает изменения в рабочей папке, которые ещё не были добавлены в индекс.

### git diff --staged

`git diff --staged` показывает изменения, которые уже находятся в индексе и подготовлены для следующего коммита.
